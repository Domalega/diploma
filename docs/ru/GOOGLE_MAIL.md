# Письма для восстановления пароля через Google Apps Script

[English](../../integrations/google-mail/README.md) · Русский

Эта инструкция поможет настроить отправку писем с аккаунта Google, если API Jotstride работает на Render. Веб-приложение Apps Script запрашивает разрешение на отправку писем. Render подписывает каждый запрос общим секретом, поэтому храните его только в Render и Apps Script.

## Настройте веб-приложение

1. Создайте проект в [Google Apps Script](https://script.google.com/home). Замените стандартный скрипт содержимым [`Code.js`](../../integrations/google-mail/Code.js).
2. В настройках проекта (**Project Settings**) включите показ манифеста в редакторе. Замените его содержимым [`appsscript.json`](../../integrations/google-mail/appsscript.json).
3. В свойствах скрипта (**Project Settings → Script properties**) добавьте `MAIL_SECRET`. Используйте случайный секрет из 32 байтов, записанный 64 шестнадцатеричными символами в нижнем регистре.
4. Один раз запустите функцию `authorizeMail`. Разрешите отправку писем с аккаунта Google, которому принадлежит скрипт.
5. Выберите **Deploy → New deployment**. Рядом с **Select type** откройте меню типов развёртывания и выберите **Web app**.
6. В поле **Execute as** выберите **Me**, а в поле **Who has access** — **Anyone**. Нажмите **Deploy** и скопируйте адрес развёртывания, который заканчивается на `/exec`.

## Настройте Render

Задайте переменные окружения для API и заново разверните сервис.

| Переменная           | Значение                                                                                       |
| -------------------- | ---------------------------------------------------------------------------------------------- |
| `MAIL_TRANSPORT`     | `google`                                                                                       |
| `GOOGLE_MAIL_URL`    | Адрес развёртывания Apps Script с окончанием `/exec`                                           |
| `GOOGLE_MAIL_SECRET` | То же значение, что и у `MAIL_SECRET`                                                          |
| `PASSWORD_RESET_URL` | `https://domalega.github.io/diploma/#/reset-password` для размещённой версии этого репозитория |

Запросите восстановление пароля для тестового аккаунта. Проверьте, что ссылка открывает форму сброса и что после смены пароля приходит второе письмо.

Веб-приложение проверяет подпись и время запроса. Оно отклоняет повтор, пока уникальный идентификатор запроса хранится в [кеше Apps Script](https://developers.google.com/apps-script/reference/cache/cache-service). При полном восстановлении пароля отправляются два письма. Они учитываются в [суточном лимите Google](https://developers.google.com/apps-script/guides/services/quotas) для аккаунта отправителя.

При локальной разработке `MAIL_TRANSPORT=outbox` сохраняет письма в `server/data/mail/`. Git игнорирует эту папку. На рабочем сервере используйте отправку через Google.
