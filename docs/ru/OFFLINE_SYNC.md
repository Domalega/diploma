# Работа без интернета на Android

[English](../OFFLINE_SYNC.md) · Русский

Для первого входа в аккаунт на Android нужен интернет. После входа можно без сети менять заметки, задачи, карточки Канбана и записи о лекарствах. Jotstride сохраняет изменения каждого аккаунта в закрытой базе SQLite на устройстве.

Ниже описана синхронизация при выключенном сквозном шифровании. Если [шифрование включено](ENCRYPTION.md#хранение-и-синхронизация), Jotstride обменивается данными, пока календарь открыт. Сохранённые зашифрованные изменения можно отправить при следующем открытии. Прежние записи на сервере сохраняются. Android Keystore защищает документы аккаунта и расписание напоминаний в обоих режимах.

## Как отправить изменения

Подключитесь к интернету и откройте Jotstride или нажмите **Обменяться сейчас** в **Настройках**. При наличии сети Android также планирует фоновую синхронизацию примерно раз в час. Система может отложить её.

Если на двух устройствах изменили разные записи, Jotstride объединит изменения. Если одну запись изменили на обоих устройствах или на одном изменили, а на другом удалили, выберите версию с телефона или с сервера. Локальное изменение останется доступным до разрешения конфликта.

Выход из аккаунта останавливает фоновую синхронизацию и удаляет сохранённые данные для входа. Неотправленные изменения останутся на телефоне до следующего входа в тот же аккаунт. При удалении приложения или очистке его хранилища эти изменения пропадут.

## Как устроен обмен

- **Объединение данных.** Заметки, задачи и отметки о приёме лекарств объединяются по отдельности. Настройки доски и настройки лекарств тоже обрабатываются отдельно.
- **Запись на телефоне.** Приложение хранит последнее состояние с сервера, текущее локальное состояние, номер поколения и сведения о текущей отправке. Изменения, сделанные во время отправки, накладываются на полученный ответ. Проверка номера поколения отклоняет устаревшие локальные записи. Если результат запроса неизвестен, клиент повторяет его с тем же идентификатором операции.
- **Запись на сервере.** API выполняет операции записи последовательно для каждого аккаунта и сохраняет подтверждение операции вместе с данными. Повтор с тем же идентификатором и данными безопасен. API отклоняет запрос с тем же идентификатором, если данные отличаются. Сопоставление с UUID сохраняет прежние числовые идентификаторы заметок.
- **История Канбана.** После обмена API сохраняет изменения по каждой задаче. Через нативный мост Android запрашивает только нужный раздел. При открытии истории приложение загружает её постранично и сохраняет страницы для просмотра без сети. Фоновая синхронизация историю не загружает. Прежние клиенты могут получить её целиком в ответе на обмен. При удалении задачи её история тоже удаляется.
- **Напоминания и данные для входа.** После фоновой синхронизации приложение пересчитывает напоминания по полному локальному снимку данных. Если запланировать напоминание не удаётся, данные календаря сохраняются. Android Keystore защищает данные для фоновой синхронизации, и нативный мост их не выдаёт. Если сеанс истёк или отозван, войдите снова, чтобы возобновить обмен.

## Как проверить офлайн-синхронизацию

Установите [предварительную версию](APPS.md#установка-и-настройка) или [соберите приложение для Android](APPS.md#android). Для проверки используйте тестовый аккаунт с выключенным сквозным шифрованием.

1. Войдите в аккаунт с доступом в интернет. Отключите сеть, измените записи и отметьте задачи выполненными. Закройте приложение, откройте снова и проверьте, что изменения сохранились.
2. Подключитесь к сети, выполните обмен и сравните записи с веб-версией. Затем измените одну запись на двух устройствах и проверьте, что приложение даёт выбрать версию.
3. Повторите проверку с отметками о приёме лекарств. Убедитесь, что напоминания об удалённых записях и лекарствах, уже отмеченных принятыми, больше не появляются. Доставку в фоне проверьте на телефоне.
