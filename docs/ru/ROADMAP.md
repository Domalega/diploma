# Планы развития Jotstride

[English](../ROADMAP.md) · Русский

Эти направления пока в проработке. Экспериментальные функции можно включить в настройках.

- **Канбан.** Проверить доску на узких экранах, со скрытыми колонками, в нескольких активных сеансах и с длинной историей действий.
- **Заметки и задачи.** Сейчас заметки календаря и задачи Канбана хранятся отдельно. Спроектировать общую модель и перенос данных между версиями с сохранением идентификаторов, владельцев, дат, времени и напоминаний.
- **Редактирование в разных представлениях.** Определить, как отмечать выполнение и настраивать напоминания, затем добавить редактирование одних и тех же записей в календаре на месяц, списке и на доске.
- **История действий.** По мере накопления данных добавить фильтры по событиям и показатели работы с задачами.
- **Расположение панелей.** Изучить возможность синхронизировать раскладку между устройствами отдельно от данных задач.
