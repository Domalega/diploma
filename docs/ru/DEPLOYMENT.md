# Развёртывание Jotstride

[English](../DEPLOYMENT.md) · Русский

Сайт Jotstride размещается на GitHub Pages, API работает на Render, а данные хранятся в PostgreSQL. Сначала разверните API, чтобы указать его адрес при сборке интерфейса.

## Как опубликовать сайт и API

1. Создайте базу PostgreSQL и разверните API по [`render.yaml`](../../render.yaml). Задайте `DATABASE_URL` на Render. Blueprint может сгенерировать `SECRET_KEY`, либо можно задать собственное случайное значение. API проверяет адрес сайта по `CLIENT_ORIGIN`. Обновите эту переменную, если используете свой домен.
2. Если на сайте нужно восстановление пароля, настройте [отправку писем через Google Apps Script](GOOGLE_MAIL.md).
3. В репозитории GitHub откройте **Settings → Pages**. В разделе **Build and deployment** выберите **GitHub Actions** в поле **Source**.
4. В **Settings → Secrets and variables → Actions** откройте вкладку **Variables** и нажмите **New repository variable**. Создайте переменную `REACT_APP_API_URL` со значением HTTPS-адреса API, который заканчивается на `/api`.
5. Отправьте изменения в `redesign`. На вкладке **Actions** дождитесь, пока процесс **Checks** соберёт и опубликует сайт.
6. Убедитесь, что `/api/health` возвращает `{"status":"ok"}`. Откройте опубликованный сайт и проверьте, что приложение связывается с API.

## Сборка и локальный просмотр сайта

[Процесс **Checks**](../../.github/workflows/ci.yml) использует такие настройки для сайта проекта.

| Переменная          | Значение                                         |
| ------------------- | ------------------------------------------------ |
| `PUBLIC_URL`        | `/diploma`                                       |
| `REACT_APP_ROUTER`  | `hash`                                           |
| `DAYMARK_SITE_URL`  | `https://domalega.github.io/diploma/`            |
| `REACT_APP_API_URL` | HTTPS-адрес развёрнутого API с окончанием `/api` |

Задайте эти переменные окружения и выполните `npm run build` из корня репозитория. Раздавайте `client/build` по пути `/diploma/`, без подстановки страницы приложения для неизвестных адресов. У отсутствующей публичной страницы должен быть ответ 404. Генератор можно проверить отдельно.

```sh
node --test scripts/build-public-site.test.cjs
```

Если используете свой домен, подключите его в GitHub Pages. В `DAYMARK_SITE_URL` укажите полный HTTPS-адрес сайта, а в `PUBLIC_URL` — путь из этого адреса или `/` для корня. Для опубликованного приложения оставьте маршрутизацию через хеш. Обновите `CLIENT_ORIGIN` и адрес восстановления пароля под новый домен.

### Что попадает в сборку

Сборка создаёт три русские страницы по адресам `/diploma/`, `/diploma/features/` и `/diploma/download/`. Английские версии находятся под `/diploma/en/`. Содержимое, метаданные, канонические адреса, ссылки на языковые версии и структурированные данные WebSite и WebPage доступны без JavaScript. Тексты сайта редактируются в [`client/site/content.cjs`](../../client/site/content.cjs), оформление — в [`client/site/site.css`](../../client/site/site.css).

Календарь открывается по адресу `/diploma/app.html#/calendar`. У страницы приложения задан `noindex`, а доступ к аккаунтам защищён входом. Главная страница перенаправляет старые ссылки, включая восстановление пароля и подключение устройств, на `app.html` и сохраняет весь фрагмент после `#`. Данные браузера остаются на прежнем домене.

Сервер разработки по-прежнему открывает интерфейс React. Android встраивает интерфейс как `index.html` при `PUBLIC_URL=.`. Сборки с обычной маршрутизацией браузера и пакет Android пропускают генерацию публичных страниц.

## Индексация в поиске

### Google Search Console

1. Добавьте `https://domalega.github.io/diploma/` как ресурс с префиксом URL. Так можно подтвердить права на раздел проекта без управления доменом `github.io`.
2. Чтобы подтвердить права HTML-файлом, положите полученный от Google файл без изменений в `client/public/` и опубликуйте сайт. Файл будет доступен под `/diploma/`. Если выбрали HTML-тег, вставьте тег Google в блок метаданных публичных страниц в [`scripts/build-public-site.cjs`](../../scripts/build-public-site.cjs).
3. Отправьте `https://domalega.github.io/diploma/sitemap.xml`. В карте сайта перечислены только канонические публичные страницы и их языковые версии. Проверьте главную страницу, возможности и загрузки на обоих языках. В Search Console можно запросить индексацию и отслеживать её ход. Отправка карты сама по себе не гарантирует появление страниц или нужную позицию в выдаче.

GitHub Pages публикует сгенерированный `robots.txt` под `/diploma/`. Поисковые роботы ищут его в корне домена, которым этот репозиторий не управляет. Поэтому отправьте карту сайта напрямую. Если проект размещён в корне собственного домена, файл уже будет по нужному адресу.

### Яндекс Вебмастер

Подтвердите права на адрес, по которому размещён сайт. Для текущего адреса проекта подтвердите `https://domalega.github.io/` через отдельный репозиторий GitHub Pages `Domalega.github.io` и опубликуйте там работающую главную страницу. Файлы из `client/public/` этого проекта доступны под `/diploma/` и для подтверждения корня не подходят. Можно также подтвердить права на собственный домен.

После подтверждения отправьте полный адрес карты сайта и запросите переобход публичных страниц. Яндекс может обнаружить публичные страницы и без регистрации в Вебмастере. [Начало работы с Яндекс Вебмастером](https://yandex.ru/support/webmaster/ru/service/quick-start)

## Развёртывание API

Если сервис Render подключён по URL публичного репозитория, разверните проверенный коммит вручную или воспользуйтесь [процессом **Render setup**](../../.github/workflows/render-setup.yml). Чтобы включить процесс, задайте переменную репозитория `RENDER_SETUP_ENABLED=true` и секрет `RENDER_API_KEY`. Если процессу нужно создать сервис, добавьте секрет `DATABASE_URL`. Для настройки почты через этот процесс задайте оба секрета — `GOOGLE_MAIL_URL` и `GOOGLE_MAIL_SECRET`.

При изменениях API в ветке `redesign` процесс дожидается успешной проверки GitHub и запрашивает развёртывание этого коммита на Render. После публикации проверьте, что `/api/health` возвращает `{"status":"ok"}`. [Режимы развёртывания Render](https://render.com/docs/deploys)
