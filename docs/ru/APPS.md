# Jotstride для Android и Windows

[English](../../apps/README.md) · Русский

Приложение для Android работает без интернета после первого входа в аккаунт. В Windows интерфейс календаря входит в сборку. Без интернета можно просматривать ранее сохранённые данные и редактировать разблокированный зашифрованный календарь, если его копия есть на устройстве. Для входа и синхронизации нужен доступ к API. Оба приложения сохраняют напоминания с указанным временем на устройстве и могут показывать их, даже когда закрыты.

## Установка и настройка

Предварительные сборки доступны в [GitHub Releases](https://github.com/Domalega/diploma/releases) и в артефактах процесса **Native apps**.

- **Android 8 и новее.** Установите APK и войдите в аккаунт. Обновляйте Android System WebView. Если переходите с версии 0.2.0, сначала прочитайте [инструкцию по переносу данных](ANDROID_UPDATES.md#переход-с-версии-020).
- **Windows 10 версии 2004 и новее или Windows 11 (x64).** При необходимости установите Microsoft Edge WebView2 Runtime. Распакуйте ZIP в постоянную папку и запустите `Daymark.exe`. Сборка для Windows не подписана. Оставьте папку на месте, поскольку задача планировщика запускает файл по этому пути.

### Как проверить напоминание при закрытом приложении

1. Откройте **Настройки** и включите уведомления. Для точного срабатывания на Android разрешите **Будильники и напоминания** в настройках системы.
2. Нажмите **Проверить уведомление** и закройте приложение. Уведомление должно прийти через пять секунд после нажатия.
3. Если уведомление не появилось, проверьте настройки уведомлений системы и условия доставки ниже.

Чтобы отменить запланированные напоминания, нажмите **Отключить напоминания на устройстве** или выйдите из аккаунта. Перед удалением приложения Windows отключите напоминания или выполните `Daymark.exe --clear`.

## Как срабатывают напоминания

Jotstride ориентируется на время устройства. Если несколько напоминаний о лекарствах приходятся на один момент, приложение объединяет их. При расчёте учитываются дни недели, даты курса и отметки о приёме. Напоминания о заметках на весь день появляются при открытии календаря.

- **Android** обновляет напоминания после фоновой синхронизации и восстанавливает их после перезагрузки, обновления приложения или изменения времени. Без разрешения на точные будильники уведомления могут запаздывать. Доставка также зависит от настроек уведомлений и ограничений батареи. После принудительной остановки откройте Jotstride снова.
- **Windows** планирует напоминания на восемь дней вперёд. Задача планировщика пополняет расписание при входе в Windows и каждый час, пока сеанс активен. Изменение системного времени учитывается при следующем пополнении расписания или открытии приложения. Чтобы получить изменения с других устройств, откройте Jotstride с доступом в интернет. После длительного сна Windows может пропустить уведомления.

На выключенном устройстве уведомления не приходят. Режимы фокусировки и «Не беспокоить» продолжают действовать. До следующей синхронизации расписание может содержать устаревшие данные. При включённом сквозном шифровании держите приложение открытым, пока оно получает изменения с других устройств.

### Где хранятся данные

На Android заметки, задачи, Канбан и сведения о приёме лекарств доступны [без интернета](OFFLINE_SYNC.md). Данные приложения хранятся в закрытом разделе с отключённым резервным копированием. Android Keystore защищает документы аккаунта, расписание напоминаний и данные для фоновой синхронизации. На Windows снимки расписания защищены DPAPI текущего пользователя. Эти снимки не содержат токенов аккаунта.

Обмен сообщениями с нативным приложением доступен только встроенному интерфейсу на Android или странице Jotstride в приложении Windows. Android 0.4.1 и обновлённый клиент Windows поддерживают системную защиту [ключей сквозного шифрования](ENCRYPTION.md).

## Сборка

Процесс **Native apps** собирает предварительные версии для обеих платформ и запускает их тесты. Файлы сборки и ключи подписи храните вне Git.

### Android

Установите Node.js 22 или новее, npm, JDK 17, Android SDK 35 и Gradle 8.11.1. Из корня репозитория соберите веб-интерфейс, затем запустите модульные тесты и соберите отладочный APK. Укажите адрес API, который поддерживает `/api/sync`.

```powershell
$env:PUBLIC_URL = '.'
$env:REACT_APP_ROUTER = 'hash'
$env:REACT_APP_API_URL = 'https://diploma-api-zozr.onrender.com/api'
npm ci --prefix client
npm run build --prefix client
gradle -p apps/android testDebugUnitTest assembleDebug
```

### Windows

Установите Node.js 22 или новее и .NET 8 SDK на Windows. Из корня репозитория соберите интерфейс, запустите тесты планировщика и соберите приложение для x64.

```powershell
$env:BUILD_PATH = '../dist/windows-web'
$env:PUBLIC_URL = '.'
$env:REACT_APP_ROUTER = 'hash'
$env:REACT_APP_API_URL = 'https://diploma-api-zozr.onrender.com/api'
npm ci --prefix client
npm run build --prefix client
dotnet run --project apps/windows/ScheduleTests
dotnet publish apps/windows/Daymark -c Release -r win-x64 --self-contained true -o dist/windows
```
